Scene Factory

                
Build batches of audio-reactive LedFx scenes, preview them, approve the good ones and send them to LedFx only when ready.

              

              

                
Preset Lab

                
Generate and edit preset drafts for existing LedFx effects. Drafts stay local until you press Send to LedFx; the Preset Bank stores reusable local bases for Scene Factory.

              

              

                
Effect Forge

                
Experimental workspace for drafting new LedFx effect module files and matching Workshop profiles. It saves files for manual review and import.

              

              

                
Live Mode

                
Performance-focused playlist launch and transport. Previous and Next only step inside the currently active LedFx playlist.

              

              

                
Show Packs

                
Export or import a portable ZIP with Workshop profiles, generated queue, LedFx scenes, playlists and user preset configuration.

              

              

                
MIDI Patch

                
Manage playlists and map playlist start, stop, previous and next controls to a Web MIDI controller in supported browsers.
